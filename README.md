**Бесплатный** github курс для освоения/повторения фреймворка LangChain, а также библиотеки LangGraph

**Для кого/чего нужен?** 

Для новичков: Получить структурированную информацию + практические задания с пояснениями и домашними заданиями для закрепления материала

Для продвинутых: Быстро вспомнить необходимую тему с возможностью заглянуть в соответствующие примеры

В папке course лежат все необходимые уроки в правильном порядке. В каждом Lesson имеется соответствующий lesson{}.md 

P.S. Постараюсь также добавлять интересные статьи/дополнительные материалы
